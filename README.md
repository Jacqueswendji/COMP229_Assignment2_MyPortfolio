# COMP229 Assignment 2 – MyPortfolio

## Project Description

This project is my personal portfolio application developed for COMP229 Web Application Development at Centennial College.

It extends my Assignment 1 portfolio by adding a Node.js and Express backend, MongoDB database integration, RESTful APIs, and JWT authentication.

## Technologies Used

- React and Vite
- Node.js and Express.js
- MongoDB and Mongoose
- JSON Web Token (JWT)
- Postman for API testing
- Git and GitHub

## Main Features

- Personal portfolio pages
- RESTful CRUD operations for contacts, projects, qualifications, and users
- MongoDB database integration
- User authentication using JWT
- Protected API routes

## Running the Application

1. Install the project dependencies.
2. Ensure MongoDB is running.
3. Configure the required environment variables, including `JWT_SECRET`.
4. Run `npm run dev` from the project root.
5. Open the frontend URL displayed by Vite.
